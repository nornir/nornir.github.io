Docker images
=============

The ``nornir-docker`` directory provides container images for running the **headless** Nornir stack (Python 3.14, no Pyre UI). Pyre is **not** shipped in these images.

* End users: install the Windows app — |pyre-windows-installer| (see :doc:`../packages/pyre_install`).
* Developers: use ``venv/pyre314`` on the host for the PyQt-based UI (see :doc:`../development/pyre_development`).
