Docker images

The nornir-docker directory provides container images for running the headless Nornir stack (Python 3.14, no Pyre UI). Pyre is not shipped in these images. Which role to launch is Run the stack. Host checks are Host requirements.

  • End users: install the Windows app — Pyre-Setup.exe (see Installing Pyre on Windows).

  • Developers: use venv/pyre314 on the host for the PyQt-based UI (see Pyre development).
