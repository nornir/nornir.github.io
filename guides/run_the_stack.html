Run the stack

Headless Nornir runs in Docker. Pyre does not. Three roles stay separate:

Role

Use it for

Start here

Programmer shell

Editable checkout, tests, Dev Containers

Cursor / local agent dev shell

Cursor agent worker

Self-hosted Cursor worker process

Cursor self-hosted cloud agent worker

Build appliance

Interactive nornir-build with NAS mounts and the dashboard

Remote build appliance

Image tags, GPU versus CPU images, and how to build them are in Image catalogue. Run one nornir-build command in a container with nd-build — run nornir-build inside Docker.

Also:

  • Build dashboard (co-located) — MQTT build dashboard on port 8087.

  • Annotation overlay gallery — annotation crop review. That image does not install Nornir.

  • Standard D:\ layout for nornir-cursor-worker — D:\Docker layout for the Cursor worker. NORNIR_DOCKER_USER_ROOT defaults to C:\Docker and is often set to D:\Docker; that page assumes D:\Docker.

Host checks (driver, WSL2, open-file limit) are in Host requirements.
